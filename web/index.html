Research experiment

How does biomedical knowledge graph composition affect R-GCN drug–drug link prediction?

About the project

A focused study of graph context in DDI link prediction.

This application presents the verified graduation-project experiment and a research demonstration of its selected G3 model.

Research question

How does biomedical knowledge graph composition affect R-GCN drug–drug link prediction?

Data

PrimeKG

The target relation is drug_drug, displayed in PrimeKG as synergistic interaction. Candidate drugs are mapped to DrugBank identifiers where available in the verified metadata.

Model

Relational Graph Convolutional Network

R-GCN learns node representations while accounting for different relationship types in a heterogeneous knowledge graph.

Evaluation

Locked, filtered ranking

  • The same DDI train/validation/test split was used for all four graph variants.
  • Held-out DDI links were excluded from message-passing adjacency.
  • Performance was evaluated using filtered ranking over 4,278 candidate drugs.
Scope & limitations

Research interpretation only

  • Results are based on PrimeKG and its synergistic-interaction Drug–Drug target relation.
  • One main GNN architecture was evaluated.
  • Robustness evaluation used three seeds; no statistical-significance claim is made.
  • Candidate predictions are unobserved PrimeKG links, not confirmed negative or positive clinical interactions.
  • This application is not a clinical decision-support tool.
Research use only

Predicted candidates represent unobserved links according to the model and PrimeKG target relation. Model scores are ranking values, not probabilities. Results must not be used for clinical decisions or medication guidance.
